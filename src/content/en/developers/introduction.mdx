This documentation covers the SokoPlus platform: its **public API**, the **data model**, and the **concepts** behind the marketplace. It's intended for developers building on top of SokoPlus or integrating their own systems.

## The platform at a glance

- **Frontend:** React 19 + TanStack Start (SSR), Tailwind CSS v4, bilingual EN/SW
- **Backend:** Node.js + Express 5 (ESM)
- **Database:** PostgreSQL 17 via Prisma 7
- **Auth:** JWT (bearer) + OTP + Google OAuth, role-based access control
- **Payments:** ClickPesa with HMAC-verified webhooks
- **Realtime:** socket.io + push notifications (web-push + Expo)

## The API

The REST API is mounted under `/api`. All responses are JSON. Mutations generally require authentication, and role-based middleware enforces who can call what.

<Callout type="note">
Throughout these docs, the base URL is shown as `https://api.sokopluss.co.tz/api`. Your actual environment may differ — check your deployment configuration.
</Callout>

## A word on stability

The platform is actively developed. Endpoint paths are stable, but response fields may evolve. Watch the `updated` dates on each page and keep an eye on the changelog.
