User and business endpoints manage profiles and the vendor/provider business records. All user endpoints below require a JWT.

## GET /user/profile

Current user profile. **Auth required.**

Returns the user object as a **flat JSON body** (not wrapped in `{status, data}`) with `businessProfile` and the default address included.

<CodeBlock title="Response">
```json
{
  "id": "...",
  "fullName": "Jane Doe",
  "email": "you@example.com",
  "role": "vendor",
  "phoneNumber": "+255700000000",
  "avatarUrl": "...",
  "businessProfile": { "businessName": "Jane's Shop", "status": "APPROVED" },
  "addresses": [
    { "id": "...", "label": "Home", "streetAddress": "...", "city": "...", "isDefault": true }
  ]
}
```
</CodeBlock>

## GET /auth/me

Full "who am I" payload. **Auth required.** The richest current-user endpoint: it resolves `businessProfile` (including its `university` and `region`), the user's own `university`, `region`, `majorAdminRegion` and `adminPermissions`, and adds `selfieVerification` and `firstName`.

<CodeBlock title="Response shape">
```json
{
  "id": "...",
  "fullName": "Jane Doe",
  "role": "vendor",
  "businessProfile": {
    "businessName": "Jane's Shop",
    "university": { "id": "...", "name": "..." },
    "region": { "id": "...", "name": "..." }
  },
  "university": { "id": "...", "name": "..." },
  "region": { "id": "...", "name": "..." },
  "majorAdminRegion": { "region": { "id": "...", "name": "..." } },
  "adminPermissions": [{ "permissionKey": "manage_orders", "enabled": true }],
  "selfieVerification": { "status": "..." },
  "firstName": "Jane"
}
```
</CodeBlock>

## PUT /user/update

Update name, phone and address fields. Also syncs the default address: it updates the existing default when one exists, or creates one labelled `Home` when `streetAddress` and `city` are both provided.

<CodeBlock title="Request">
```json
{
  "fullName": "Jane Doe",
  "phoneNumber": "+255700000000",
  "streetAddress": "123 Sam Nujoma Road",
  "district": "Kinondoni",
  "ward": "Mikocheni",
  "city": "Dar es Salaam"
}
```
</CodeBlock>

## PUT /user/avatar

Upload a new avatar image (multipart, field name `avatar`). Returns the updated `avatarUrl`.

## PUT /user/password

<CodeBlock title="Request">
```json
{ "currentPassword": "old", "newPassword": "new" }
```
</CodeBlock>

Returns `401` with `Invalid current password` when the current password is wrong.

## Addresses (`/api/user/addresses`)

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | `/user/addresses` | JWT | List your addresses (soft-deleted excluded) |
| POST | `/user/addresses` | JWT | Create an address (see body below) |
| DELETE | `/user/addresses/:id` | JWT | Soft-delete an address |

<CodeBlock title="POST /user/addresses">
```json
{
  "label": "Home",
  "streetAddress": "123 Sam Nujoma Road",
  "city": "Dar es Salaam",
  "district": "Kinondoni",
  "ward": "Mikocheni",
  "isDefault": true
}
```
</CodeBlock>

Setting `isDefault: true` clears `isDefault` on the user's other addresses.

## Payment methods (`/api/user/payments`)

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | `/user/payments` | JWT | List saved payment methods |
| POST | `/user/payments` | JWT | Save a payment method |

<CodeBlock title="POST /user/payments">
```json
{ "type": "mobile_money", "provider": "M-Pesa", "accountNumber": "+255700000000", "isDefault": true }
```
</CodeBlock>

## DELETE /user/account

Soft-deletes your own account: sets `deletedAt` while preserving the data in records. **Auth required.**

## Role changes & activity logs

- `PUT /users/change-role` and `GET /users/activity-logs` **do not exist**. Role changes are performed by admins only via `PUT /admin/users/:userId/role` (protected by `partnerAdmin`/`majorAdmin`/`superAdmin` and scoped to region). Activity logs are admin-only via `GET /admin/activity`.
- Referral info lives in the [referrals API](./api-referrals): `GET /referrals/my`, `GET /referrals/code` and `POST /referrals/apply`.

## Business endpoints (`/api/business`)

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | `/business/all` | Public | Approved businesses with counts |
| GET | `/business/:id` | Public | Business detail + products + services |
| PUT | `/business/update` | vendor+ | Upsert business profile |
| PUT | `/business/logo` | vendor+ | Upload logo |
| PUT | `/business/cover` | vendor+ | Upload cover image |
| GET | `/business/verification-status` | vendor+ | Live approval status |

<Callout type="note">
Business status must be `APPROVED` before the owner can list products or services.
</Callout>
