These endpoints handle user-to-user communication and platform content.

## Notifications (`/api/notifications`)

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | `/notifications` | JWT | Your notifications |
| PUT | `/notifications/:id/read` | JWT | Mark single read |
| PUT | `/notifications/read-all` | JWT | Mark all read |
| DELETE | `/notifications/clear` | JWT | Clear all |
| POST | `/notifications/register-token` | JWT | Register web-push subscription |
| PUT | `/notifications/update-expo-token` | JWT | Update Expo push token |
| GET | `/notifications/preferences` | JWT | Get preferences |
| PUT | `/notifications/preferences` | JWT | Update preferences |
| POST | `/notifications/notify-all` | admin | Notify everyone |
| POST | `/notifications/notify-vendor` | admin | Notify vendors |

Preferences: `order_updates`, `promotions`, `general`.

## Messaging (`/api/messages`)

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| POST | `/messages` | JWT | Send message |
| GET | `/messages/conversations` | JWT | Conversations + unread counts |
| GET | `/messages/:userId` | JWT | Thread with a user |
| PUT | `/messages/:id/read` | JWT | Mark single read |
| PUT | `/messages/read/:userId` | JWT | Mark all from a user read |
| GET | `/messages/unread/count` | JWT | Total unread |

## Content & support (`/api/content`)

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | `/content/platform/:key` | Public | CMS page (privacy, terms) |
| PUT | `/content/platform/:key` | superAdmin | Upsert CMS page |
| GET | `/content/faq` | Public | Active FAQs |
| GET | `/content/faq/all` | partnerAdmin+ | All FAQs |
| POST/PUT/DELETE | `/content/faq...` | partnerAdmin+ | FAQ CRUD |
| POST | `/content/support/tickets` | JWT | Create ticket |
| GET | `/content/support/tickets` | JWT | Your tickets |
| GET | `/content/support/tickets/all` | partnerAdmin+ | All tickets |
| PUT | `/content/support/tickets/:id` | partnerAdmin+ | Update status |
| POST | `/content/support/tickets/:id/reply` | partnerAdmin+ | Reply |
