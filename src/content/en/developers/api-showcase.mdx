Uploads are handled by `multer` (in-memory, per-file limit **5 MB**) and forwarded to Cloudinary. All endpoints require a **JWT**.

## Upload / KYC (`/api/upload`)

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| POST | `/upload/selfie` | JWT | Upload a selfie photo — multipart, field `file` |
| POST | `/upload/document` | JWT | Upload a KYC document — multipart, field `file` |

Both accept a single file at a time — `image/*` or `application/pdf` — up to **5 MB**. Sending more than one file, or an oversized file, returns `400`.

<Callout type="note">
For KYC verification, each file (selfie, ID document, business document) is uploaded one at a time. Upload the selfie first, then the documents.
</Callout>

## Showcase projects (`/api/showcase`)

**Showcase** projects are curated projects displayed on the explore/showcase page.

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | `/showcase` | — | List showcase projects |
| POST | `/showcase/create` | superAdmin | Create a showcase project (multipart, field `image`) |
| PUT | `/showcase/:id` | superAdmin | Update a showcase project |
| DELETE | `/showcase/:id` | superAdmin | Delete a showcase project |
