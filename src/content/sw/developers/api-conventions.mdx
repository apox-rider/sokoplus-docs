Kila endpoint kwenye rejea hii inafuata mikataba hiyo hiyo.

## URL ya msingi

```text
https://api.sokopluss.co.tz/api
```

## Bahasha ya majibu

Majibu yenye mafanikio hutumia bahasha moja thabiti:

<CodeBlock title="Success shape">
```json
{
  "status": "success",
  "data": { ... }
}
```
</CodeBlock>

Baadhi ya endpoints hurudisha safu (array) ya kiwango cha juu au kitu bapa; angalia mfano wa kila endpoint.

## Muundo wa hitilafu

Hitilafu daima hurudisha hali ya `4xx`/`5xx` pamoja na:

<CodeBlock title="Error shape">
```json
{
  "status": "error",
  "message": "Human-readable explanation",
  "code": "OPTIONAL_MACHINE_CODE"
}
```
</CodeBlock>

| Hali | Maana |
|--------|---------|
| `400` | Ombi baya / uthibitisho umeshindwa |
| `401` | Tokeni haipo au si sahihi |
| `403` | Jukumu haliruhusiwi |
| `404` | Rasilimali haikupatikana |
| `429` | Kikomo cha maombi (rate limit) kimefikiwa |
| `503` | Kipengele kimezimwa (feature guard) |

## Pagination

Endpoints za orodha hukubali vigezo vya `page` na `limit` vya query na hurudisha data iliyogawanywa kwa kurasa, kwa mfano:

<CodeBlock title="Paginated shape">
```json
{
  "status": "success",
  "data": {
    "items": [],
    "page": 1,
    "limit": 20,
    "total": 143,
    "totalPages": 8
  }
}
```
</CodeBlock>

## Kuchuja na kutafuta

Endpoints nyingi za orodha hutumia vichujio vya `search`, `category`, `sort` na vingine kupitia vigezo vya query. Endpoint ya [utafutaji wa jumla](/sw/developers/api-orders) hutoa utafutaji unaovuka huluki nyingi (cross-entity).

## Kufuta kwa upole (soft delete)

Rasilimali zilizowekwa alama ya `deletedAt` zimefutwa kwa upole: hazionekani kwenye queries za kawaida lakini zinabaki kwenye hifadhidata hadi msimamizi atakapozifuta kabisa.

## Tarehe na saa

Mihuri yote ya wakati inarudishwa kama **mifuatano ya ISO 8601** ya UTC.
