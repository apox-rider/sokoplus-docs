Endpoints zote za uthibitishaji ziko chini ya `/api/auth`.

## POST /auth/signup

Sajili mtumiaji mpya. Inatuma OTP kwa barua pepe/simu iliyotolewa.

```json
{
  "email": "you@example.com",
  "password": "secret",
  "fullName": "Jane Doe",
  "phoneNumber": "+255700000000",
  "role": "client"
}
```

| Sehemu | Inahitajika | Maelezo |
|-------|----------|-------|
| `email` | Ndiyo | Barua pepe sahihi |
| `password` | Ndiyo | Angalau herufi 6 |
| `fullName` | Ndiyo | Jina kamili |
| `phoneNumber` | Ndiyo | Kwa ajili ya OTP |
| `role` | Hapana | `client` ni chaguo-msingi; `vendor`/`service_provider` huanza wakiwa inasubiri |

## POST /auth/login

Kuingia kwa barua pepe + nenosiri. Inarudisha `data.token`.

## POST /auth/otp/verify

```json
{ "code": "123456", "email": "you@example.com", "phoneNumber": "+255700000000" }
```

Inarudisha JWT wakati msimbo utakapothibitishwa.

## POST /auth/me

`GET` wasifu wa mtumiaji wa sasa ukijumuisha `businessProfile` na anwani ya msingi. **Uthibitishaji unahitajika.**

## Kurejesha nenosiri

| Endpoint | Body | Madhumuni |
|----------|------|---------|
| `POST /auth/forgot-password/send` | `{ "email" }` | Tuma OTP ya kuweka upya |
| `POST /auth/forgot-password/verify` | `{ "code", "email" }` | Thibitisha msimbo wa kuweka upya |
| `POST /auth/forgot-password/reset` | `{ "email", "code", "password" }` | Weka nenosiri jipya |

## Kuingia kwa Google

`POST /auth/google` ukitumia `{ "idToken" }` kutoka kwa mteja wa Google OAuth. Inarudisha JWT.

## Endpoints nyingine

| Method | Path | Auth | Maelezo |
|--------|------|------|-------------|
| POST | `/auth/otp/send` | — | Tuma OTP ya uthibitishaji |
| POST | `/auth/otp/link` | JWT | Unganisha simu na akaunti |
| POST | `/auth/logout` | JWT | Batilisha kipindi (session) |
| POST | `/auth/refresh` | — | Fanya upya tokeni |
| POST | `/auth/check-exists` | — | Angalia uwepo wa mtumiaji |
| POST | `/auth/change-password` | JWT | Badilisha nenosiri |

<Callout type="note">
Endpoints fulani za pekee (kama kuingia kama mtumiaji mwingine) zimehifadhiwa kwa wasimamizi wa jukwaa na hazijatolewa hadharani.
</Callout>
