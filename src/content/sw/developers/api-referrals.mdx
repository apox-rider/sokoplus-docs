Mpango wa rufaa na mfumo wa mikopo ni kipengele kimoja, kinachodhibitiwa na bendera moja `ecommerce:referral_credits`. Bendera ikizimwa, endpoints za watumiaji hapa chini zinarudisha `503` pamoja na ujumbe uliosanidiwa; endpoints za msimamizi haziathiriwi.

<CodeBlock title="Kipengele kimezimwa (503)">
```json
{
  "message": "Referral system is currently unavailable",
  "feature": "referral_credits",
  "enabled": false
}
```
</CodeBlock>

Endpoints zote zinahitaji JWT. Endpoints za msimamizi zinahitaji pia jukumu la `superAdmin`.

## Zawadi za rufaa

Mikopo hutolewa wakati rufaa inapowekwa alama kuwa imekamilika:

| Nani | Mikopo | Maelezo |
|------|--------|-------------|
| Mwalikaji (referrer) | 5,000 | Zawadi ya rufaa kwa kumwalika mtumiaji |
| Aliyefikishwa (referred) | 2,000 | Zawadi ya kukaribishwa baada ya kurejelewa |

Rufaa iliyokamilika hurekodi `rewardAmount: 7000` (5,000 + 2,000). Mikopo iliyopatikana huisha muda wake baada ya **miezi 6**.

## Rufaa (`/api/referrals`)

| Method | Path | Auth | Maelezo |
|--------|------|------|-------------|
| GET | `/referrals/my` | JWT | Watumiaji waliofikishwa na mtumiaji wa sasa |
| GET | `/referrals/stats` | JWT | Takwimu za rufaa |
| GET | `/referrals/code` | JWT | Msimbo wako wa rufaa (hutengeneza na kuhifadhi mmoja usipokuwepo) |
| POST | `/referrals/apply` | JWT | Omba msimbo wa rufaa wa mtu mwingine |
| GET | `/referrals/admin/all` | superAdmin | Rufaa zote (kwa kurasa) |

### GET /referrals/my

<CodeBlock title="Jibu (Response)">
```json
{
  "referrals": [
    {
      "id": "...",
      "status": "pending",
      "expiresAt": "2026-11-07T00:00:00.000Z",
      "rewardAmount": null,
      "createdAt": "2026-08-07T00:00:00.000Z",
      "referred": { "id": "...", "fullName": "Jane Doe", "email": "jane@example.com", "createdAt": "2026-08-07T00:00:00.000Z" }
    }
  ]
}
```
</CodeBlock>

### GET /referrals/stats

<CodeBlock title="Jibu (Response)">
```json
{
  "stats": {
    "totalReferrals": 3,
    "completedReferrals": 1,
    "pendingReferrals": 2,
    "totalCreditsEarned": 7000
  }
}
```
</CodeBlock>

### GET /referrals/code

Inarudisha msimbo wa rufaa wa mtumiaji wa sasa, na hutengeneza na kuhifadhi mmoja usipokuwepo. Misimbo huanza na kiambishi `SP-` kikifuatwa na herufi 8 (`A`–`Z`, `0`–`9`).

<CodeBlock title="Jibu (Response)">
```json
{ "referralCode": "SP-AB12CD34" }
```
</CodeBlock>

### POST /referrals/apply

<CodeBlock title="Ombi (Request)">
```json
{ "referralCode": "SP-AB12CD34" }
```
</CodeBlock>

| Status | Hali |
|--------|------|
| `200` | Msimbo umetumika — `{ "message": "Referral code applied successfully" }` |
| `400` | Msimbo haukupatikana, umeshatumika, au unatumia msimbo wako mwenyewe |
| `404` | Msimbo si sahihi / hautambuliki |

Msimbo wa rufaa unaweza kutumika mara moja tu, na kamwe usitumie msimbo wako mwenyewe. Rekodi ya rufaa huanza ikiwa `pending`.

### GET /referrals/admin/all

Vigezo vya hoja (query): `page`, `limit` (msingi `1`, `20`) na kichujio cha hiari `status`.

<CodeBlock title="Jibu (Response)">
```json
{
  "referrals": [ ... ],
  "pagination": { "page": 1, "limit": 20, "total": 42, "pages": 3 }
}
```
</CodeBlock>

## Mikopo (`/api/credits`)

| Method | Path | Auth | Maelezo |
|--------|------|------|-------------|
| GET | `/credits/my` | JWT | Salio la sasa la mikopo |
| GET | `/credits/history` | JWT | Historia ya miamala ya mikopo |
| POST | `/credits/redeem` | JWT | Tumia mikopo kwa kipengele cha mfumo |
| GET | `/credits/admin/user/:userId` | superAdmin | Mikopo na miamala ya mtumiaji |
| POST | `/credits/admin/adjust` | superAdmin | Rekebisha mikopo ya mtumiaji kwa mikono |

### GET /credits/my

<CodeBlock title="Jibu (Response)">
```json
{
  "credits": {
    "id": "...",
    "userId": "...",
    "balance": 5000,
    "totalEarned": 5000,
    "totalRedeemed": 0,
    "totalExpired": 0
  }
}
```
</CodeBlock>

### GET /credits/history

<CodeBlock title="Jibu (Response)">
```json
{
  "history": [
    {
      "id": "...",
      "type": "earned",
      "amount": 5000,
      "description": "Referral reward for referring user",
      "referenceType": "referral",
      "referenceId": "...",
      "expiresAt": "2027-02-07T00:00:00.000Z",
      "createdAt": "2026-08-07T00:00:00.000Z"
    }
  ]
}
```
</CodeBlock>

Thamani za `type`: `earned` (zilipatikana), `redeemed` (zilitumiwa), `adjusted` (za msimamizi), `expired` (ziliisha muda wake).

### POST /credits/redeem

Mwili `{ "feature": "...", "amount": ... }` — `amount` ni hiari na hupata thamani ya gharama ya kipengele kwa msingi.

| Feature | Gharama (mikopo) |
|---------|----------------|
| `product_boost` | 500 |
| `service_pin` | 500 |
| `featured_listing` | 1,500 |
| `pro_trial` | 2,000 |
| `pro_month` | 5,000 |
| `business_month` | 10,000 |

<CodeBlock title="Ombi (Request)">
```json
{ "feature": "product_boost" }
```
</CodeBlock>

<CodeBlock title="Jibu (Response)">
```json
{
  "message": "Credits redeemed successfully",
  "credit": { "id": "...", "userId": "...", "balance": 4500, "totalEarned": 5000, "totalRedeemed": 500, "totalExpired": 0 }
}
```
</CodeBlock>

Kipengele kisichotambulika kinarudisha `400` pamoja na orodha ya `validFeatures`; salio lisilotosha linarudisha `400` na ujumbe `Insufficient credits`.

<Callout type="note">
Mikopo hutumika kwa kuilipia kipengele cha mfumo kupitia `POST /credits/redeem` — haitolewi kiotomatiki kwenye malipo ya agizo (checkout).
</Callout>

### GET /credits/admin/user/:userId

<CodeBlock title="Jibu (Response)">
```json
{
  "user": { "id": "...", "fullName": "Jane Doe", "email": "jane@example.com" },
  "credits": { "id": "...", "userId": "...", "balance": 5000, "totalEarned": 5000, "totalRedeemed": 0, "totalExpired": 0 },
  "transactions": [ ... ]
}
```
</CodeBlock>

### POST /credits/admin/adjust

<CodeBlock title="Ombi (Request)">
```json
{
  "userId": "...",
  "amount": 1000,
  "description": "Promotional bonus"
}
```
</CodeBlock>

`amount` lazima iwe nambari isiyo sifuri. Thamani chanya huongeza `totalEarned`; thamani hasi huongeza `totalRedeemed` na hukataliwa kwa `400` zikizidi salio la sasa.

<CodeBlock title="Jibu (Response)">
```json
{ "message": "Credits adjusted successfully", "credit": { ... } }
```
</CodeBlock>
