Arifa zinawafanya watumiaji kuwa na taarifa. Backend huzitoa kupitia njia tatu: **ndani ya programu (in-app)**, **Expo push** (simu), na **web push** (kivinjari).

## Njia

| Njia | Utaratibu | Lini |
|---------|-----------|------|
| In-app | Safu za `Notification` + socket.io emit | Daima |
| Expo push | `expoPushToken` kwenye mtumiaji, `expo-server-sdk` | Programu za simu |
| Web push | `WebPushSubscription` + maktaba ya web-push (VAPID) | Kivinjari |

## Kujisajili kwa push

```bash
# Simu (tokeni ya Expo)
curl -X PUT https://api.sokopluss.co.tz/api/notifications/update-expo-token \
  -H "Authorization: Bearer <token>" \
  -d '{"expoPushToken": "ExponentPushToken[...]"}'

# Wavuti (usajili wa push)
curl -X POST https://api.sokopluss.co.tz/api/notifications/register-token \
  -H "Authorization: Bearer <token>" \
  -d '{"subscription": {"endpoint": "...", "keys": {"auth": "...", "p256dh": "..."}}}'
```

## Mapendeleo

Watumiaji wanaweza kukandamiza aina za arifa kupitia `GET/PUT /api/notifications/preferences`.

| Mapendeleo | Hudhibiti |
|------------|----------|
| `order_updates` | Hali ya agizo, usafirishaji, escrow |
| `promotions` | Matangazo, kukuza tangazo, kuponi |
| `general` | Mengine yote |

## Kinachochochea arifa

- Agizo limewekwa / hali imebadilika
- Usafirishaji umekabidhiwa / umethibitishwa
- Ujumbe mpya
- Uidhinishaji / ukataliwa wa muuzaji
- Matukio ya malipo au kurudishiwa fedha
- Mabadiliko ya swichi za vipengele (yatangazwa kwa hadhira)

## Kutuma matangazo (msimamizi)

| Mbinu | Njia | Maelezo |
|--------|------|-------------|
| POST | `/api/notifications/notify-all` | Aarifu kila mtumiaji |
| POST | `/api/notifications/notify-vendor` | Aarifu wauzaji wote |

<Callout type="note">
`notify-all` inaweza kuwa ghali — inatumwa kwa kila tokeni iliyosajiliwa. Itumie kwa uchache.
</Callout>

## Vidokezo vya usalama

- Usiwahi kuweka kwenye logi `expoPushToken` au funguo za faragha za VAPID.
- Funguo za VAPID zinapaswa kuwa kwenye vigezo vya mazingira (`VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`).
- Heshimu mapendeleo ya watumiaji kabla ya kutuma push za matangazo.
