Endpoints za watumiaji na biashara zinasimamia wasifu na rekodi za biashara za muuzaji/mtoa huduma. Endpoints zote za watumiaji hapa chini zinahitaji JWT.

## GET /user/profile

Wasifu wa mtumiaji wa sasa. **Uthibitishaji unahitajika.**

Inarudisha kitu cha mtumiaji kama **JSON bapa** (hakijafungwa katika `{status, data}`) ikijumuisha `businessProfile` na anwani ya msingi.

<CodeBlock title="Jibu (Response)">
```json
{
  "id": "...",
  "fullName": "Jane Doe",
  "email": "you@example.com",
  "role": "vendor",
  "phoneNumber": "+255700000000",
  "avatarUrl": "...",
  "businessProfile": { "businessName": "Jane's Shop", "status": "APPROVED" },
  "addresses": [
    { "id": "...", "label": "Home", "streetAddress": "...", "city": "...", "isDefault": true }
  ]
}
```
</CodeBlock>

## GET /auth/me

Maelezo kamili ya "wewe ni nani". **Uthibitishaji unahitajika.** Huu ndio endpoint tajiri zaidi kuhusu mtumiaji wa sasa: unatatua `businessProfile` (ikijumuisha `university` na `region` yake), `university`, `region`, `majorAdminRegion` na `adminPermissions` za mtumiaji mwenyewe, na kuongeza `selfieVerification` na `firstName`.

<CodeBlock title="Muundo wa jibu">
```json
{
  "id": "...",
  "fullName": "Jane Doe",
  "role": "vendor",
  "businessProfile": {
    "businessName": "Jane's Shop",
    "university": { "id": "...", "name": "..." },
    "region": { "id": "...", "name": "..." }
  },
  "university": { "id": "...", "name": "..." },
  "region": { "id": "...", "name": "..." },
  "majorAdminRegion": { "region": { "id": "...", "name": "..." } },
  "adminPermissions": [{ "permissionKey": "manage_orders", "enabled": true }],
  "selfieVerification": { "status": "..." },
  "firstName": "Jane"
}
```
</CodeBlock>

## PUT /user/update

Sasisha sehemu za jina, simu na anwani. Pia inasawazisha anwani ya msingi: inaisasisha ikiwa tayari ipo, au inaunda moja yenye lebo `Home` wakati `streetAddress` na `city` zote zimetolewa.

<CodeBlock title="Ombi (Request)">
```json
{
  "fullName": "Jane Doe",
  "phoneNumber": "+255700000000",
  "streetAddress": "123 Sam Nujoma Road",
  "district": "Kinondoni",
  "ward": "Mikocheni",
  "city": "Dar es Salaam"
}
```
</CodeBlock>

## PUT /user/avatar

Pakia picha mpya ya avatar (multipart, jina la sehemu `avatar`). Inarudisha `avatarUrl` iliyosasishwa.

## PUT /user/password

<CodeBlock title="Ombi (Request)">
```json
{ "currentPassword": "old", "newPassword": "new" }
```
</CodeBlock>

Inarudisha `401` na ujumbe `Invalid current password` ikiwa nenosiri la sasa si sahihi.

## Anwani (`/api/user/addresses`)

| Method | Path | Auth | Maelezo |
|--------|------|------|-------------|
| GET | `/user/addresses` | JWT | Orodhesha anwani zako (zilizofutwa kwa upole hazijumuishwi) |
| POST | `/user/addresses` | JWT | Unda anwani (tazama ombi hapa chini) |
| DELETE | `/user/addresses/:id` | JWT | Futa anwani kwa upole |

<CodeBlock title="POST /user/addresses">
```json
{
  "label": "Home",
  "streetAddress": "123 Sam Nujoma Road",
  "city": "Dar es Salaam",
  "district": "Kinondoni",
  "ward": "Mikocheni",
  "isDefault": true
}
```
</CodeBlock>

Kuweka `isDefault: true` kunafuta `isDefault` kwenye anwani nyingine za mtumiaji.

## Njia za malipo (`/api/user/payments`)

| Method | Path | Auth | Maelezo |
|--------|------|------|-------------|
| GET | `/user/payments` | JWT | Orodhesha njia za malipo zilizohifadhiwa |
| POST | `/user/payments` | JWT | Hifadhi njia ya malipo |

<CodeBlock title="POST /user/payments">
```json
{ "type": "mobile_money", "provider": "M-Pesa", "accountNumber": "+255700000000", "isDefault": true }
```
</CodeBlock>

## DELETE /user/account

Inafuta akaunti yako kwa upole: inaweka `deletedAt` huku ikihifadhi data katika rekodi. **Uthibitishaji unahitajika.**

## Mabadiliko ya jukumu na kumbukumbu za shughuli

- `PUT /users/change-role` na `GET /users/activity-logs` **hazipo**. Mabadiliko ya jukumu hufanywa na wasimamizi pekee kupitia `PUT /admin/users/:userId/role` (yanayolindwa na `partnerAdmin`/`majorAdmin`/`superAdmin` na kuwekewa mipaka ya mkoa). Kumbukumbu za shughuli ni za wasimamizi pekee kupitia `GET /admin/activity`.
- Taarifa za rufaa zinapatikana kwenye [API ya rufaa](./api-referrals): `GET /referrals/my`, `GET /referrals/code` na `POST /referrals/apply`.

## Endpoints za biashara (`/api/business`)

| Method | Path | Auth | Maelezo |
|--------|------|------|-------------|
| GET | `/business/all` | Public | Biashara zilizoidhinishwa pamoja na idadi |
| GET | `/business/:id` | Public | Maelezo ya biashara + bidhaa + huduma |
| PUT | `/business/update` | vendor+ | Unda au sasisha wasifu wa biashara |
| PUT | `/business/logo` | vendor+ | Pakia nembo (logo) |
| PUT | `/business/cover` | vendor+ | Pakia picha ya jalada (cover) |
| GET | `/business/verification-status` | vendor+ | Hali ya idhini ya moja kwa moja |

<Callout type="note">
Hali ya biashara lazima iwe `APPROVED` kabla ya mmiliki kuweza kuorodhesha bidhaa au huduma.
</Callout>
